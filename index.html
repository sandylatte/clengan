                Import & export

                Excel in, Excel out

                Import a planner

                One-off, adds rows

                Reads a spreadsheet once. Any table with a Category (or Item) column and an Amount (or Cost) column is found wherever it sits, with Date and Note if it has them. A table under a Fixed or Flexible heading keeps that bucket. Adds to what is already here rather than replacing it.

                Sample data

                Six made-up months

                Fills the app with six months of made-up transactions, across four accounts, so every screen has something to show. Added alongside anything already here, never in place of it — and every row is labelled in its note, so Remove takes back exactly what Load added.

                Sync

                Off

                Keep the same ledger on more than one device. Everything is encrypted on this device before it is sent, so the server stores what it cannot read.

                There is no password reset. The password is what decrypts your records, so nobody — including whoever runs the server — can recover it for you. Creating an account gives you a recovery code; that code is the only other way in.

                Signing out leaves every record on this device. It only forgets the account.

                No server is provided. Point this at one you run yourself — see server/ in the repository.

                App version

                The shell is served from an offline cache, so a stale one keeps showing old numbers with no sign anything is wrong. This names the version actually running and forces a fresh copy.
